# A short note on reserved names, keywords and Python 3.12

The ".example" name is recommended for use in documentation or as examples. [RFC 2606](https://www.rfc-editor.org/rfc/rfc2606.txt)

The word MUST means that the definition is an absolute requirement of the specification. [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119.txt)

The new release brought more flexible f-string parsing, allowing many things previously disallowed. [Python 3.12.0 release](https://www.python.org/downloads/release/python-3120/)

IANA agreed to reserve the test names so they would never be delegated in the global DNS. [RFC 2606](https://www.rfc-editor.org/rfc/rfc2606.txt)

RFC 2606 was published in June 2001. [RFC 2606](https://www.rfc-editor.org/rfc/rfc2606.txt)

Python 3.12 removed the Global Interpreter Lock for all programs. [Python 3.12.0 release](https://www.python.org/downloads/release/python-3120/)
